# Program KPI Waterfall Model

## Standard Benchmarks

| Stage | Standard |
| --- | ---: |
| Accounts in market | 100% |
| Engaged accounts | 30% |
| Sales meetings scheduled | 10% |
| Pipeline opportunities | 50% |
| Closed deals | 30% |

## Inputs

Customer-editable inputs:

- program type
- program name
- segment / audience
- channels
- content / messaging
- notes
- benchmark mode: `Standard` or `Custom`
- accounts targeted
- average deal size
- custom in-market, engage, meeting, pipeline, and close rates

## Outputs

Calculated outputs:

- accounts in market
- engaged accounts
- sales meetings
- pipeline opportunities
- closed deals
- pipeline goal
- bookings

## Sample Verification

With `1,200` accounts targeted, `$5,000,000` average deal size, and standard benchmarks:

- accounts in market: `1,200`
- engaged accounts: `360`
- sales meetings: `36`
- pipeline opportunities: `18`
- closed deals: `5`
- pipeline goal: `$90,000,000`
- bookings: `$25,000,000`
